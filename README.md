# Browse++ A C++ Browser Engine from Scratch.

A custom-built C++ web browser engine written from scratch to support HTTP and HTTPS, with a web and desktop version.

## Features

- HTTP & HTTPS networking

- Parsing and DOM generation

- Terminal UI (for now)
